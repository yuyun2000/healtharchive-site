HealthArchive 用于保存个人检查报告、记录症状与用药、核对结果并回看变化。它不是医疗机构，不提供诊断或治疗建议，导出的内容是个人归档副本，不是医疗机构病历或医疗证明。

1. 本机归档与可选联网

报告归档、文字识别、人工核对、浏览、指标比较、备份和恢复可以在本机完成，无需注册 HealthArchive 账号。可选 AI 功能需要联网，由你自行配置第三方 HTTPS 模型服务。请求从设备直接发送到该地址，不经过开发者转发。

开发者没有用于接收个人档案的业务服务器。当前 App 没有广告、分析 SDK、遥测或跨 App 跟踪，也不会自动向开发者发送报告、使用行为或错误报告。不能据此把所有功能称为“完全离线”：启用 AI、使用你选择的云端文件来源或分享目的地时，相应服务可能需要联网。

2. 设备上保存的资料

你导入的 PDF／图片副本、识别原文、报告标题和机构、结果与参考范围、来源页、日期、人工修改、核对状态，以及症状、用药和就诊记录保存在设备上。原始字段和本人原话用于追溯，不因显示名称统一而被覆盖。人工归类、采集条件和报告整理进度也保存在本机。

App 使用 iOS 的本地文件保护，不启用 iCloud／CloudKit 同步。本机档案库和保存的原件被排除在自动系统备份之外，请主动导出备份。文件选择器和照片选择器只用于你主动选择的资料；导入产生本机副本，不删除你在“文件”或照片图库中的原件。

只有你选择拍照时才请求相机权限，用于拍摄报告或就诊材料；不会自动把拍摄结果写入照片图库。照片选择器只读取你选中的图片，不申请整个图库的访问权限。多页照片经你确认页序后在本机形成一份 PDF，作为本次归档原件；它保留页面图像，不保证还原相册源文件的字节或拍摄元数据。未保存的临时照片在取消或退出收集页时清理。

PDF 文字读取与图片 OCR 在本机进行。OCR 和 AI 都可能识别错误，保存候选不等于人工确认。

3. 模型配置与访问密钥

服务地址、模型名称、接口偏好和连接检测结果保存在本机。API Key 保存在系统钥匙串，只用于向你配置的服务验证身份，不放入报告、使用记录或导出备份，也不发送给开发者。

你可以在“设置 → AI 模型设置”清除配置。卸载前建议先清除密钥；不能假定卸载 App 一定清除系统钥匙串里的凭据。如果密钥已泄露，请同时在服务商处撤销或更换。

4. AI 发送前的选择与同意

保存资料不会自动发送给模型。你主动发起 AI 操作后，App 会说明目的、服务地址和发送范围，确认后才开始。不同功能使用不同范围：

  • 报告整理与记录整理：所选报告／就诊材料的文字、所需页面图片或本人输入。报告整理会分批提取、复查和补漏，可能产生多次请求；登记复核也可能使用该报告已有的候选结果、参考范围、采样条件和来源片段。不会因此读取其他报告。
  • 归类复核：所选项目的名称、值、单位、样本信息和来源片段，以及必要的报告标题、机构或同报告相关片段。模型只给候选，需你确认才应用。
  • 查询查看范围：你的需求、设备日期、公开目录和预览的本机项目名称／分组。项目名称也是健康资料；这一步不附结果值、原文或原件，查看计划不会自动应用。
  • 核对与修复：先确认发送需求和报告名称／日期／项目目录来定位；再单独确认所选结果、来源原文及最多三个相关来源页的图片。建议需你查看预览并应用，修正结果退回待核对，原字段和出处保留。
  • 连接检测：你选择保存并测试时，发送少量合成样例文字与图片，不发送健康报告。

整页图片和来源文字可能包含姓名、证件号、就诊号、二维码、联系方式、机构，以及未选中的项目。App 不保证自动遮盖这些信息。发送前应检查范围；不接受整页内容离开设备时，请取消并采用本机人工核对。

5. 第三方接收后的处理

模型服务由你选择，App 不经开发者服务器转发。服务商会收到请求内容、验证凭据，以及建立连接所需的网络信息。其保存期限、处理地区、训练用途、分包商和删除方式取决于该服务商及你的账号设置；开发者无法统一保证其留存或删除规则。

请先阅读服务商政策并确认适合发送健康资料。服务商可能位于境外，发送前应核对其处理地区。兼容某个接口不代表具备相同的隐私保护，App 的设置也不等于服务商承诺不留存。

你可以在发送前取消，或暂停、取消正在处理的任务，阻止后续请求。报告整理在获授权后可继续跨界面运行，返回上一页不代表取消；请使用任务的暂停或取消入口。已发送的内容无法从设备撤回，删除本机记录也不会删除服务商副本；需要时应联系服务商处理。

6. 本地请求记录与保留期限

App 在本机保存实际请求的用途、模型、时间、接口、相关页数、状态和服务返回的用量／标识，方便检查使用情况和处理来源。请求历史不保存发送正文、模型响应正文、报告原文、文件名或 API Key。报告本身仍保存提取候选和来源，供你核对。

档案和整理进度保留到你主动删除。可在“设置 → AI 使用记录”清空请求历史；删除报告会清理报告、结果、相关归类／采集条件和整理进度，但已保存的请求元数据及模型处理来源可解除报告关联后保留，用于追溯。不再需要的请求历史需另行清空。

7. 删除、备份与分享

你可以删除本机报告或健康记录。共享的原件副本仅在没有其他记录引用时清理。删除不影响你原先选择的外部文件，也不会自动清理已导出、已分享或第三方已收到的副本。重要资料请先备份。

完整备份和可恢复分享 ZIP 无需密码、没有加密，可能包含原文、身份信息、人工修改、请求元数据和原件。模型连接设置与 API Key 不进入备份。此前导出的加密备份仍需原密码恢复。

范围分享按你的选择生成内容；明确附带整份原件时，它可能包含范围外的资料。请在发送前预览，妥善保管导出文件，并自行删除或撤销分享目的地中的副本。恢复只处理本机资料，不会自动发起模型请求。

8. Apple 健康与付款

当前版本不向 Apple 健康写入数据，也不会自动请求其访问权限。仅在你明确选择时，可清理本 App 早前版本创建的健康样本，不删除其他来源的健康数据。

App 将始终保持免费下载，当前版本没有内购、订阅或付款功能。未来新增付费功能计划采用一次购买的非消耗型内购，通过 Apple 的 StoreKit／App Store 处理交易，并在上线前更新相关说明；这一能力目前尚未实现。第三方 AI 服务可能另行收费，由你与服务商按其条款结算。

9. 网站与主动联系

本网站是静态隐私与支持页面，不设置账号、在线表单、Cookie、统计脚本、遥测或远程页面资源。浏览网页时，静态托管服务仍可能处理 IP 地址、浏览器信息和访问时间等连接资料。正式托管方及访问日志规则将在网站上线前核对并补充；目前没有公开托管网址。

你主动发送支持邮件时，开发者会收到邮件地址、邮件内容和你附上的资料，仅用于处理该请求。邮件服务商还会按其规则处理投递和留存。请不要发送 API Key、证件号码或完整健康报告。开发者会在问题处理结束后删除不再需要的支持邮件和附件；你可通过同一邮箱提出删除请求，依法必须保留的内容除外。
